# Show the draft before asking

When you ask me to approve something (a reply, a ticket, a PR description, a review verdict, a message), I approve what I can read. Anything I haven't seen, I haven't approved.

- **The full text goes in your visible reply first**, before the approval question. A draft that only exists in your thinking, a tool call, or a file I haven't opened has not been shown. In the desktop app the `wrap_up` question ends the turn, so the draft has to come before that call.
- **The recap never says "shown above"** or "as drafted" unless the text really is above, in this turn.
- **Every button is a complete instruction.** A button that sends "Change it first:" arrives with nothing after the colon. If I might want edits, leave that to the free-text reply instead of offering a button for it.
- **Posting needs approval of this exact text.** If the text changes after I approve it, show me the new version and ask again.
