# Show the draft before asking

I read the turn's final message. Text you write earlier in the turn, between tool calls, can reach me cut to a summary or not at all, and so does anything that exists only in your thinking, a tool call, or a file I haven't opened. So when you ask me to approve something (a reply, a ticket, a PR description, a review verdict, a message), I approve what that final message shows me. Anything I haven't seen, I haven't approved.

- **The full text goes in the final message.** In the desktop app that is the message after the `wrap_up` call, and the `wrap_up` question asks about the text it carries.
- **A reference to shown text sits in the same message as the text.** "Shown above", "here is the draft" and "as drafted" are true only when the text is in the message that says so. Before sending, find the text each one points at in that message. The `wrap_up` recap carries no such reference, since it is read away from the transcript.
- **Every button is a complete instruction.** A button that sends "Change it first:" arrives with nothing after the colon. If I might want edits, leave that to the free-text reply instead of offering a button for it.
- **Posting needs approval of this exact text.** If the text changes after I approve it, show me the new version and ask again.
