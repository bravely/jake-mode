# Write code test-first

Build features and fix bugs test-first through the `tdd` skill (`/tdd`, or `/mattpocock-skills:tdd` when only the plugin provides it), whether or not I ask for it.

- **Every public method gets its own specs this way**, testing it directly rather than only through a caller.
- **Delegated code too.** Tell subagents, arena candidates and side sessions that write code to work test-first, and check their specs before accepting their diff.
- **Skip it** for changes with no behaviour to test (docs, prose, config, pure renames), or when I say to.
