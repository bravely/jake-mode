# Session renaming

Name the session as soon as it's clear what it's about. How depends on the harness:

- **Desktop app** (the `mcp__ccd_session_mgmt__set_session_title` tool exists, possibly deferred; load it with ToolSearch): rename the session yourself with `session_id: "self"` during your reply to the first message. Don't ask first, and don't also suggest a `/rename`. If my first message is too vague to name, rename once the scope settles. If I set the title myself, the app asks me before replacing it; that prompt is expected.
- **Terminal** (no such tool): I can't run `/rename` myself, so suggest it as **one copyable string** with the command included, `/rename 🧹 Remove mattpocock/skills`, appended without asking permission.

Either way, the name is:

- **Plain English, not a slug.** Spaces, slashes, punctuation are all fine. (Branch names are a separate rule and stay kebab-case.)
- **Led by one emoji** that fits the session. Playfully suitable is encouraged; don't stack them.

Name it once when the shape is clear, and again only if the focus meaningfully shifts.
