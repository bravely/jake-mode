# Session rename suggestions

Once it's clear what a session is about (a few exchanges in, or when the scope settles), proactively suggest a session name. I can't run `/rename` myself, so:

- Give it as **one copyable string** with the command included: `/rename 🧹 Remove mattpocock/skills`.
- **Plain English, not a slug.** Spaces, slashes, punctuation are all fine. (Branch names are a separate rule and stay kebab-case.)
- **Lead with one emoji** that fits the session — playfully suitable is encouraged; don't stack them.
- Don't ask permission, just append the one-liner. Suggest once when the shape is clear, and again only if the focus meaningfully shifts.
