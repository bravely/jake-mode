# Conventional Comments when reviewing others' code

When I review someone else's code, every comment the author will read is written as a [Conventional Comment](https://conventionalcomments.org/): `<label> [decorations]: <subject>`, then the discussion.

- **Scope:** inline diff comments, thread replies on their PR, and each point in the summary body of a review I submit.
- **The label tells the author what to do with it.** A `question` is one I want answered; a problem I'm sure of is an `issue`.
- **Every comment states whether it blocks**, with `(blocking)` or `(non-blocking)`, unless the label already settles it (`praise`, `nitpick`).
- **Still drafts.** These go out from my account, so `code-review-replies` applies: show me the labelled drafts and post only after I approve the exact text.
